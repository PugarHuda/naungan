# Naungan against the Digital Public Goods Standard

A self-assessment against the nine indicators of the [DPG Standard](https://digitalpublicgoods.net/standard/) of the Digital Public Goods Alliance, written before applying. Each line points to what can be checked in this repository or on the live deployment, and says plainly where Naungan falls short.

| # | Indicator | Where Naungan stands |
|---|---|---|
| 1 | **Relevance to the SDGs** | SDG 1.5 (resilience of the poor to climate-related extreme events and disasters), SDG 13.1 (resilience and adaptive capacity to climate hazards), SDG 10.2 (inclusion). Every live program uses the trigger of a published Red Cross / Red Crescent Early Action Protocol (`lib/program.mjs`, each preset linked to its source). |
| 2 | **Open licence** | MIT for all code (`LICENSE`). The data the triggers read is open: Copernicus GloFAS (Copernicus licence), NOAA GEFS (public domain), ECMWF open data (CC BY 4.0), WorldPop (CC BY 4.0), country borders from country-coder (ISC). |
| 3 | **Clear ownership** | Copyright Pugar Huda Mantoro (`LICENSE`), source at github.com/PugarHuda/naungan. **Gap:** a single individual owns it; a DPG is better held by an organisation, and that is not yet the case. |
| 4 | **Platform independence** | No admin key: `contracts/Naungan.sol` has no owner, no upgrade path and no pause, so programs keep paying if this project disappears. The contract runs on any EVM chain and takes any ERC-20 at deployment (`constructor(semaphore, token)`), so USDC on Base is a choice, not a lock-in. The relayer is optional: `claim()` accepts a proof from any sender, and `node scripts/relayer.js` runs anywhere, not only on Vercel; Upstash Redis is optional (`/health` reports which store is in use). Oracles are `node scripts/oracle.js` with any key a coordinator names; Open-Meteo is open source and can be self-hosted. **Gap:** the hosted relayer and oracles today are run by the project, and the Circle faucet is the only source of testnet USDC. |
| 5 | **Documentation** | `README.md` (every component, how to run the whole system locally and on Base Sepolia, what is real and its limits), `docs/PROPOSAL.md`, OpenAPI 3.1 for the open data (`web/public/openapi.json`), `SECURITY.md`. |
| 6 | **Non-personal data extractable in open formats** | All program data is open and keyless: JSON, GeoJSON (RFC 7946), HXL CSV, Atom, IATI 2.03 and CAP 1.2 (`api/`), plus the CSV/JSON ledger export on the dashboard, and the chain itself. IATI and CAP output is validated in CI against the official schemas. |
| 7 | **Privacy and applicable laws** | No personal data is stored by Naungan: the chain holds Semaphore commitments, nullifiers and payout addresses only; dedup between agencies uses private set intersection, so names never leave an agency's computer; the relayer keeps no identity, and a push endpoint is deleted after one push. Identity checks (KYC, sanctions screening) stay with the enrolling agency, off-chain, under its own legal duties. **Gap:** no legal review has been done for any jurisdiction; payouts to self-custodied wallets raise AML questions a deploying agency must answer with its regulator. |
| 8 | **Standards and best practices** | Humanitarian: IATI, HXL, CAP, Red Cross EAP triggers, the Core Humanitarian Standard for feedback (anonymous, verified ratings). Web: WCAG checked with axe on every page in CI, CSP and security headers, `security.txt` (RFC 9116). Engineering: 96 contract and service tests, 71 frontend tests, 74 Playwright tests, Slither static analysis, Sourcify-verified contract. |
| 9 | **Do no harm by design** | 9A data privacy & security: above, plus PIN-locked cards (20 tries, server-checked OPRF), no household identifiable on-chain, and an honest note in the README on who *can* recognise a printed card's claim (the agency that printed it) and how self-registration avoids it. 9B inappropriate content: Naungan hosts no user content; the only free text is program metadata written by a coordinator's own wallet, and it is escaped wherever shown and guarded against spreadsheet formula injection in CSV. 9C harassment: there is no messaging between users; household feedback is a rating and a fixed topic, nothing free-form. |

## What it costs to run

The dashboard's **Running costs** panel prices this deployment's own transactions on Base mainnet on every visit (gas price, the L1 data fee from Base's GasPriceOracle, ETH/USD from Chainlink). On 22 Oct 2026 it showed: a claim about $0.005, an oracle report about $0.0008, enrolling a household about $0.003. A program with two oracles reporting four times a day for a year costs about $2.45 in gas, and enrolling and paying 1,000 households about $8 more. Hosting runs on free tiers (Vercel, GitHub Actions, Upstash).
